# 文献阅读进度

为 Zotero **10.0.x** 制作的个人插件。在文献列表的标题后显示当前阅读进度，下拉选择即可修改：

**未开始 → 已初读 → 已精读 → 已复现**

## 安装

1. 打开 Zotero，进入 **工具 → 插件**（部分界面称“附加组件”）。
2. 点击齿轮，选择 **从文件安装插件…**。
3. 从 GitHub Releases 获取 `zotero-reading-progress-1.1.0.xpi`，选择它，按提示完成安装。
4. 返回“我的文库”。标题右边出现进度选择框。若未立即出现，重启 Zotero。

不用双击 XPI，也不用解压。源码包中的 `.test-run` 是隔离测试资料库，不要将其导入真实文献库。

## 使用

- 点击标题后的状态框，选择四种状态之一。每篇文献只保留一种状态，可跳级、回退。
- 新增文献没有进度标签，自动显示“未开始”。原有的未标记文献也显示“未开始”。
- 不会根据标题里的“已读”推断阶段，也不会修改已有标题。
- “已复现”始终排在当前文献列表末尾；两组内部保持当前标题、作者、时间等排序规则，升序、降序都适用。
- 改回其他状态后，文献恢复到前面组中的正常位置。
- 可以多选文献，右键 → **设置阅读进度**，批量设置。
- 只对顶层文献及独立附件显示进度；子附件和子笔记跟随父文献。
- 只读文献库、回收站中的文献不能修改状态。
- 标题列过窄时，可拖宽标题列；状态框会占用约 100 像素显示空间。

## 保存位置与卸载

进度保存在 Zotero 普通标签中：`阅读进度/已初读`、`阅读进度/已精读`、`阅读进度/已复现`。无这些标签即“未开始”，不需要为每篇文献额外写入默认标签。原有科学主题标签会保留。

若用户本身已开启 Zotero 数据同步，这些普通标签随原有同步配置处理；插件不启用同步，也不接入外部存储。标签同步冲突导致多个状态标签并存时，显示最高阶段；下次设置时规范为单一状态。

停用或卸载插件后，下拉框和置底规则消失，进度标签仍保留。重新安装后可继续显示。

1.1.0 已配置 GitHub Releases 更新地址。首次将仓库上传并成功发布后，需要从 Releases 手动安装一次 1.1.0，之后 Zotero 可按自动更新设置获取新版。1.0.0 的占位更新地址无法自动找到 1.1.0。

发布准备和后续操作见 [PUBLISH.md](PUBLISH.md)。本地已验证构建和更新清单；线上发布及更新下载仍需在仓库创建后验证。

## 开发与验证

```text
node --test tests/*.test.cjs
python build.py
```

`tests/prepare-live.py` 为本机 Zotero 准备完全隔离的测试配置及测试插件，自动测试脚本不进入交付的 XPI。真实程序测试覆盖状态默认值、下拉写入、升降序置底、回退、子笔记层次、停用和重新启用。

本版通过 Zotero 10 的内部主列表接口实现标题内显示。未来 Zotero 大版本需要重新适配，因此安装包限定为 10.0.x，不承诺兼容 Zotero 7、8、9 或 11。
